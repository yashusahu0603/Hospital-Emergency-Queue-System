Hospital Emergency Queue System

About the Project

The Hospital Emergency Queue System is a console-based Java application designed to manage patients according to their emergency priority.

Technologies Used

- Java
- IntelliJ IDEA

Data Structures Used

- Priority Queue
- Min Heap
- Linked List

Features

- Add New Patient
- View All Patients
- View Emergency Queue
- Treat Next Patient
- Search Patient
- Delete Patient

Priority Levels

1. Critical
2. Serious
3. Moderate
4. Normal

How to Run

1. Download or clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the Main.java file.
